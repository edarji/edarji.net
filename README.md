# edarji.net

Sitio personal estático de Eduardo ArJi, preparado para GitHub Pages.

## Editar el contenido

- `index.html`: textos, secciones y enlaces. Busca los comentarios `EDITAR`.
- `styles.css`: colores, tipografía y diseño responsive.
- `script.js`: menú móvil, navegación activa y animaciones.
- `assets/eduardo-saxofon.jpeg`: imagen principal.

## Publicar

Sube todos los archivos a la raíz del repositorio `edarji/edarji.net`. GitHub Pages
servirá automáticamente `index.html`, y el archivo `CNAME` conservará el dominio
personalizado `edarji.net`.

## MEM Monitor

Sección estática en `mem-monitor/`, enlazada desde el menú y Proyectos.
Diseño Blue Session, inspirado en el ambiente de Kind of Blue: azul noche,
tonos fríos, tipografía editorial y datos legibles.

Conecta fuentes públicas CENACE: demanda neta SIN, PML MDA por nodo y generación
liquidada mensual SEN. Cada panel muestra su propio corte, unidad y fuente.

Consulta [la documentación del monitor](mem-monitor/README.md) para actualizar
los datos, conocer sus límites y revisar el flujo Python → JSON → GitHub Pages.
